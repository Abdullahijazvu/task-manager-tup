# TaskFlow

A simple task management web app for organizing tasks across different workspaces.

## Features

- **Workspaces** — Organize tasks into Personal and Work spaces
- **CRUD Operations** — Create, edit, and delete tasks
- **Task Properties** — Title, description, priority (Low/Medium/High), status (To Do/In Progress/Done), and due date
- **Search** — Search tasks by title or description
- **Filters** — Filter by status and priority, sort by due date
- **Activity Log** — Tracks recent actions in the sidebar
- **Persistence** — All data saved to localStorage, survives page refresh
- **Responsive** — Works on desktop and mobile

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 19 + TypeScript
- Vite
- Plain CSS
- localStorage for persistence
